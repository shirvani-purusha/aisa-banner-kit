# AISA banner kit · Coffee and Conversation (DRAFT)

**DRAFT CONCEPT · EVENT AND CO-SPONSORSHIP UNCONFIRMED.** These are review
mockups for a proposed collaboration between AISA and the Howard Thurman
Center. The event, its title, time zone, venue, registration and
co-branding are not confirmed. Bracketed `[CONFIRM: …]` items are
placeholders, not facts.

## Contents

- `banner-kit/` is the editable implementation: the review presentation and
  three banner masters (1920×1080, 1920×640, mobile 1080×1350), built so the
  identity layer, event copy, graphic and per-format layouts can each be
  changed independently. Start with [`banner-kit/README.md`](banner-kit/README.md).
- `project/` is the original Claude Design export the kit was built from:
  Design Component files, SVG masters, PNG previews, and the companion
  documents (specification, accessibility review, text companion and alt
  text, approval checklist).

## Live site

The repository root deploys to GitHub Pages as static files, with no build step.
The root `index.html` forwards to `banner-kit/`.
